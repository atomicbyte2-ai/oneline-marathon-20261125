# One-Liner Marathon — The Dentist

> I told my dentist I floss daily, and he nodded like a man who has heard that exact lie for twenty years.

`main.ts` writes the line above to `entry.txt` in the output directory
(`process.env.MAKEFUN_OUTPUT_DIR` or `/output`).
